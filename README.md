# 주짓수 화이트벨트 영상

노량진 주짓수락 화이트벨트 가이드라인의 기술을 누르면 영상으로 연결되는 정적 웹페이지입니다.
영상 주소를 지정하지 않은 기술은 유튜브 검색 결과로 연결됩니다. 서버나 빌드 과정 없이 GitHub Pages에서 그대로 열립니다.

## 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 공개 페이지 |
| `admin.html` | 관리자 페이지 (기술 목록, 화면 꾸미기, 저장 설정) |
| `data.js` | 사이트 내용 전체. 관리자 페이지에서 저장하면 자동으로 바뀝니다 |
| `config.properties` | 관리자 설정 (관리자 비밀번호, GitHub 연결 기본값) |
| `css/`, `js/` | 화면 스타일과 스크립트 |

## GitHub Pages로 열기

1. 저장소의 `Settings` → `Pages`로 들어갑니다.
2. `Build and deployment`의 Source를 `Deploy from a branch`로 두고, Branch를 `main`, 폴더를 `/ (root)`로 선택한 뒤 `Save`를 누릅니다.
3. 1~2분 뒤 `https://계정명.github.io/저장소명/` 주소로 열립니다.

## 관리자 페이지 사용법

공개 주소 뒤에 `admin`을 붙여 접속합니다. 고친 뒤 **저장** 버튼(또는 `Ctrl+S`) 하나만 누르면 됩니다.

### 저장하면 일어나는 일

- **GitHub를 연결해 둔 경우**: 저장소의 `data.js`가 자동으로 커밋되고 1~2분 뒤 공개 페이지에 반영됩니다. `저장 설정`에서 "저장할 때마다 data.js 파일도 내려받기"를 켜면 같은 내용이 파일로도 내려받아집니다(백업용).
- **연결하지 않은 경우**: `data.js` 파일을 내려받습니다. 받은 파일을 저장소의 `data.js`와 교체해 커밋하면 반영됩니다.

### 기술 목록 탭

- 기술 이름, 영상 주소, 영어 검색어를 한 줄에서 고칩니다. 영상 주소를 비우면 유튜브 검색으로 연결됩니다.
- 유튜브 주소를 붙여넣으면 썸네일이 보여서 맞는 영상인지 바로 확인할 수 있습니다. `찾기`를 누르면 그 기술의 유튜브 검색이 새 탭으로 열립니다.
- 위쪽 검색창으로 기술을 찾고, "영상 없는 기술만"으로 아직 영상을 넣지 않은 기술만 모아 볼 수 있습니다.
- 큰 분류, 작은 분류, 기술은 추가, 삭제, 순서 변경이 됩니다. 잘못 지웠으면 `실행 취소`로 되돌립니다.
- `변경 버리기`는 저장하지 않은 변경을 모두 버리고 마지막으로 저장된 내용으로 돌아갑니다.
- 저장하지 않은 편집 내용은 이 브라우저에 자동으로 보관되어, 창을 닫았다 열어도 이어서 작업할 수 있습니다. `미리보기`로 저장 전 모습을 확인합니다.

### 화면 꾸미기 탭

공개 페이지에 보이는 글자와 색을 모두 여기서 바꿉니다.

- 맨 위 제목, 제목 위 작은 글씨, 소개 글
- 점수표 (칸 추가, 삭제)
- 검색창 안내 글, 검색 결과가 없을 때 보이는 글
- 유튜브 검색에 붙일 단어, 한국어/영어 버튼 글자와 표시 여부
- 맨 아래 안내 글, 관리자 링크 글자와 표시 여부
- 강조 색, 보조 색, 화면 모드(기기 설정에 맞춤 / 항상 밝게 / 항상 어둡게)

### 저장 설정 탭: GitHub 연결 (처음 한 번)

1. GitHub 오른쪽 위 프로필 → `Settings` → `Developer settings` → `Personal access tokens` → `Fine-grained tokens` → `Generate new token`
2. `Repository access`는 `Only select repositories`로 이 저장소만 선택합니다.
3. `Permissions` → `Contents`를 `Read and write`로 바꿉니다. 다른 권한은 필요 없습니다.
4. 관리자 페이지 `저장 설정` 탭 → `GitHub 연결` → "토큰을 파일로 만들기 / 직접 입력"에 토큰을 붙여넣고 `이 토큰을 PC 파일로 저장`을 누릅니다. 저장할 폴더와 파일 이름을 직접 고르면 바로 연결됩니다.
5. `연결 확인`을 누릅니다. 저장소 주인과 이름은 주소에서 자동으로 채워집니다.

이미 토큰 파일(내용이 토큰 한 줄인 텍스트 파일)이 있다면 `토큰 파일 선택`으로 그 파일을 고르면 됩니다.

연결해 두면 관리자 페이지를 열 때마다 저장소의 최신 내용을 자동으로 불러옵니다.

#### 토큰은 어디에 있나요

- 토큰은 **브라우저에 저장하지 않습니다.** 이 PC에서 직접 고른 파일에서만 읽고, 이 저장소나 GitHub API 외의 곳으로는 보내지 않습니다.
- Chrome, Edge: 한 번 고른 파일을 기억해 두었다가, 다음 접속부터 `저장`이나 `연결 확인`을 누를 때 "파일 읽기 허용" 창이 뜹니다. 허용하면 읽습니다. (브라우저에는 파일 위치 정보만 남고 토큰 내용은 남지 않습니다.)
- Firefox, Safari: 접속할 때마다 `토큰 파일 선택`으로 파일을 골라야 하고, 읽은 토큰은 그 탭을 닫으면 사라집니다.
- 파일은 폴더가 아니라 파일 하나를 고르는 방식입니다. 브라우저가 문서/다운로드/바탕화면 폴더 전체의 접근은 막기 때문입니다.
- 토큰 파일은 이 저장소 폴더 밖에 두세요. 실수로 커밋하면 토큰이 공개됩니다.
- 예전 버전에서 브라우저에 저장해 둔 토큰은 자동으로 지워지고, 그 접속에서만 쓰입니다. 걱정되면 GitHub에서 그 토큰을 폐기하고 새로 만드세요.

### 관리자 비밀번호 (`config.properties`)

관리자 설정은 저장소 맨 위의 `config.properties` 파일로 관리합니다.

```properties
# 관리자 페이지 비밀번호 (암호화된 값)
admin.password.salt=
admin.password.hash=

# 글자 그대로 적는 비밀번호 (권하지 않음)
admin.password=

# GitHub 연결 기본값
github.owner=kyeongha2857-code
github.repo=bjj-videos-static
github.branch=main
github.path=data.js
```

- **비밀번호 정하기**: 관리자 페이지 `저장 설정` 탭의 "관리자 비밀번호"에서 정하면, 암호화된 값(`salt`, `hash`)이 이 파일에 자동으로 저장됩니다. 1~2분 뒤부터 관리자 페이지를 열 때 비밀번호를 물어봅니다.
- **비밀번호를 잊었을 때**: GitHub에서 `config.properties`를 열어 `admin.password.salt`와 `admin.password.hash` 값을 지우면 비밀번호 없이 열립니다. 다시 관리자 페이지에서 새로 정하세요.
- **직접 적기**: `admin.password=원하는비밀번호`처럼 글자 그대로 적어도 동작합니다. 다만 공개 저장소에서는 누구나 이 파일을 읽을 수 있으므로 권하지 않습니다.
- **GitHub 기본값**: `github.*` 값은 관리자 페이지의 GitHub 연결 칸에 미리 채워집니다. 토큰은 이 파일에 절대 넣지 마세요.

비밀번호는 관리자 화면을 가리는 용도입니다. 이 사이트에는 서버가 없어서 비밀번호 확인이 브라우저 안에서 이루어지므로, 잘 아는 사람은 우회할 수 있습니다. 내용을 실제로 바꾸는 것은 GitHub 토큰이 있어야만 가능하니, 토큰 관리가 진짜 잠금장치입니다.

### 알아둘 점

- 저장은 GitHub 토큰을 가진 사람만 할 수 있습니다. 토큰이 없으면 자기 브라우저의 초안만 바뀝니다.
- 두 곳에서 동시에 고치면 나중에 저장한 쪽이 이깁니다. 이전 내용은 저장소의 커밋 기록에서 되돌릴 수 있습니다.
- 화면이 비어 보이거나 예전 모습이 나오면 브라우저가 옛 파일을 기억하고 있는 것입니다. `Ctrl+F5`(맥은 `Cmd+Shift+R`)로 새로고침하세요.
