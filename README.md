# 주짓수 화이트벨트 영상

노량진 주짓수락 화이트벨트 가이드라인의 기술을 누르면 영상으로 연결되는 정적 웹페이지입니다.
영상 주소를 지정하지 않은 기술은 유튜브 검색 결과로 연결됩니다. 서버나 빌드 과정 없이 GitHub Pages에서 그대로 열립니다.

## 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 공개 페이지 |
| `admin.html` | 설정 페이지 (모든 항목 편집) |
| `data.js` | 기술 목록. 화면에 보이는 내용은 전부 여기서 옵니다 |
| `css/`, `js/` | 화면 스타일과 스크립트 |

## GitHub Pages로 열기

1. 저장소의 `Settings` → `Pages`로 들어갑니다.
2. `Build and deployment`의 Source를 `Deploy from a branch`로 두고, Branch를 `main`, 폴더를 `/ (root)`로 선택한 뒤 `Save`를 누릅니다.
3. 1~2분 뒤 `https://계정명.github.io/저장소명/` 주소로 열립니다.

## 영상 주소 바꾸기

방법은 두 가지입니다.

**설정 페이지 사용**
1. `admin.html`을 엽니다. (공개 주소 뒤에 `admin.html`을 붙이거나, 내려받은 폴더에서 파일을 직접 엽니다.)
2. 기술의 영상 주소 칸에 `https://youtu.be/...`를 넣습니다. 비워 두면 유튜브 검색으로 연결됩니다. 섹션, 그룹, 기술의 추가, 삭제, 순서 변경도 모두 가능합니다.
3. 편집 내용은 이 브라우저에 초안으로 자동 저장되고, `초안 미리보기`로 공개 페이지 모양을 확인할 수 있습니다.
4. `data.js 내려받기`로 받은 파일을 저장소의 `data.js`와 교체해 커밋합니다. GitHub 웹에서는 파일 화면의 `Add file` → `Upload files`로 같은 이름의 파일을 올리면 됩니다.

**data.js 직접 수정**
GitHub 웹에서 `data.js`를 열고 연필 아이콘으로 편집합니다. 기술 항목의 `"video": ""`에 주소를 넣으면 됩니다.

서버가 없기 때문에 설정 페이지에는 로그인이 없습니다. 다른 사람이 열어도 자기 브라우저의 초안만 바뀔 뿐, 공개 페이지에는 영향이 없습니다. 공개 페이지에 반영되는 것은 저장소에 커밋된 `data.js`뿐입니다.
