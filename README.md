# 주짓수 화이트벨트 영상

노량진 주짓수락 화이트벨트 가이드라인의 기술을 누르면 영상으로 연결되는 정적 웹페이지입니다.
영상 주소를 지정하지 않은 기술은 유튜브 검색 결과로 연결됩니다. 서버나 빌드 과정 없이 GitHub Pages에서 그대로 열립니다.

## 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 공개 페이지 |
| `admin.html` | 설정 페이지 (모든 항목 편집) |
| `data.js` | 기술 목록. 화면에 보이는 내용은 전부 여기서 옵니다 |
| `css/`, `js/` | 화면 스타일과 스크립트 |

## GitHub Pages로 열기

1. 저장소의 `Settings` → `Pages`로 들어갑니다.
2. `Build and deployment`의 Source를 `Deploy from a branch`로 두고, Branch를 `main`, 폴더를 `/ (root)`로 선택한 뒤 `Save`를 누릅니다.
3. 1~2분 뒤 `https://계정명.github.io/저장소명/` 주소로 열립니다.

## 영상 주소 바꾸기

`admin.html`(공개 주소 뒤에 `admin.html`을 붙여 접속)에서 모든 항목을 고치고 **GitHub에 저장**을 누르면, 저장소의 `data.js`가 자동으로 커밋되고 1~2분 뒤 공개 페이지에 반영됩니다. 저장은 `Ctrl+S`로도 됩니다.

### 처음 한 번만: GitHub 토큰 만들기

1. GitHub 오른쪽 위 프로필 → `Settings` → `Developer settings` → `Personal access tokens` → `Fine-grained tokens` → `Generate new token`
2. `Repository access`는 `Only select repositories`로 이 저장소만 선택합니다.
3. `Permissions` → `Contents`를 `Read and write`로 바꿉니다. 다른 권한은 필요 없습니다.
4. 만료일을 정하고 토큰을 만든 뒤, 설정 페이지의 `GitHub 연결`에 저장소 정보와 함께 붙여넣고 `연결 정보 저장`을 누릅니다.

토큰은 입력한 브라우저에만 저장되고 GitHub API 외에는 전송되지 않습니다. 공용 PC라면 `이 브라우저에 토큰을 기억하기`를 끄고 쓰세요(브라우저를 닫으면 지워집니다).

### 설정 페이지 기능

- 섹션, 그룹, 기술의 이름, 영어 검색어, 영상 주소를 모두 수정하고, 추가, 삭제, 순서 변경을 할 수 있습니다. 영상 주소를 비우면 유튜브 검색으로 연결됩니다.
- `초안 미리보기`: 저장하기 전 공개 페이지 모양을 확인합니다. 편집 내용은 이 브라우저에 초안으로 자동 보관됩니다.
- `GitHub에서 불러오기`: 저장소의 최신 `data.js`를 편집 화면으로 가져옵니다. 다른 곳에서 수정했거나, 저장 직후 배포 반영을 기다리는 동안 최신 내용을 보고 싶을 때 씁니다.
- `data.js 내려받기`, `파일 가져오기`: 토큰 없이 파일로 주고받을 때 씁니다.

### data.js 직접 수정

GitHub 웹에서 `data.js`를 열고 연필 아이콘으로 편집해도 됩니다. 기술 항목의 `"video": ""`에 주소를 넣으면 됩니다.

### 알아둘 점

- 설정 페이지 자체에는 로그인이 없습니다. 저장은 토큰을 가진 사람만 할 수 있고, 토큰이 없으면 자기 브라우저의 초안만 바뀝니다.
- 저장하면 `data.js`가 통째로 새로 커밋되므로, 두 곳에서 동시에 고치면 나중에 저장한 쪽이 이깁니다. 이전 내용은 저장소의 커밋 기록에서 되돌릴 수 있습니다.
