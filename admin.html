영상 설정

기술 이름, 영어 검색어, 영상 주소를 모두 고칠 수 있습니다. 영상 주소를 비워 두면 유튜브 검색으로 연결됩니다.

저장하면 GitHub 저장소의 data.js가 바로 업데이트되고, 1~2분 뒤 공개 페이지에 반영됩니다. 처음 한 번만 아래 GitHub 연결 정보를 입력해 주세요.

GitHub 연결설정 필요
  1. GitHub 오른쪽 위 프로필 → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  2. Repository access는 Only select repositories로 이 저장소만 고르세요.
  3. Permissions → Contents를 Read and write로 바꾸세요. (다른 권한은 필요 없습니다)
  4. 만료일을 정하고 만든 뒤, 한 번만 보이는 토큰을 위 칸에 붙여넣으세요.

토큰은 이 브라우저에만 저장되고 GitHub 외에는 어디로도 전송되지 않습니다. 이 저장소에 쓸 수 있는 권한이라 남에게 알려주지 마세요.
