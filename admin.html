저장할 때

관리자 비밀번호 없음

비밀번호를 정하면 이 페이지를 열 때 비밀번호를 물어봅니다. 비밀번호는 저장소의 config.properties 파일에 암호화된 값으로 저장됩니다.

이 비밀번호는 관리자 화면을 가리는 용도입니다. 실제로 내용을 바꾸려면 아래 GitHub 토큰이 있어야 하므로, 토큰을 남에게 알려주지 않는 것이 가장 중요합니다.

GitHub 연결 설정 필요

연결해 두면 [저장]을 누를 때 저장소의 data.js가 자동으로 바뀌고, 1~2분 뒤 공개 페이지에 반영됩니다.

토큰 만드는 방법
  1. GitHub 오른쪽 위 프로필 → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  2. Repository access는 Only select repositories로 이 저장소만 고르세요.
  3. Permissions → Contents를 Read and write로 바꾸세요. 다른 권한은 필요 없습니다.
  4. 만료일을 정해 만든 뒤, 한 번만 보이는 토큰을 위 칸에 붙여넣고 [연결 확인]을 누르세요.

토큰은 이 브라우저에만 저장되고 GitHub 외에는 어디로도 전송되지 않습니다. 이 저장소에 쓸 수 있는 권한이라 남에게 알려주지 마세요.
