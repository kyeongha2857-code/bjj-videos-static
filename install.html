주짓수 樂 가이드
앱 설치

아이폰과 안드로이드 모두 홈 화면에서 주소창 없이 앱처럼 열 수 있습니다. 쓰시는 기기의 설치 방법을 따라 해 주세요.

카카오톡 같은 앱 안에서 열린 화면에서는 설치되지 않을 수 있습니다. 메뉴에서 Safari로 열기(아이폰) 또는 다른 브라우저로 열기(안드로이드)를 눌러 주세요.
지금 보고 계신 기기는 컴퓨터로 보입니다. 설치할 휴대폰에서 이 페이지를 다시 열어 주세요.
앱 아이콘 설치하기

설치 순서

  1. 위 버튼을 누르고 "구성 프로파일을 다운로드하려고 합니다" 창에서 허용을 누릅니다.
  2. 설정 앱을 열면 맨 위에 "프로파일이 다운로드됨"이 보입니다. 눌러서 설치를 누릅니다. (찾을 수 없으면 설정 → 일반 → VPN 및 기기 관리)
  3. 잠금 화면 암호를 입력하고, "서명되지 않음" 경고가 나오면 설치를 한 번 더 누릅니다.
  4. 홈 화면에 주짓수 樂 아이콘이 생깁니다. 눌러서 열어 보세요.
설치 창이 안 뜨고 파일이 다운로드되기만 한다면 아이폰의 파일 앱 → 다운로드 폴더에서 jiujitsu 파일을 누르세요. 그러면 설정 앱에서 설치할 수 있습니다.
이 프로파일은 앱 아이콘 하나만 추가합니다. 개인정보를 수집하거나 기기 설정을 바꾸지 않습니다. 지우려면 설정 → 일반 → VPN 및 기기 관리 → 주짓수 樂 가이드 → 프로파일 삭제를 누르면 아이콘도 함께 사라집니다.
앱 다운로드 (APK)

설치 순서

  1. 위 버튼을 눌러 jiujitsu.apk를 내려받습니다. "이 파일은 기기에 해를 끼칠 수 있습니다" 경고가 나오면 확인 또는 그래도 다운로드를 누릅니다.
  2. 다운로드가 끝나면 알림이나 내 파일 → 다운로드에서 파일을 엽니다.
  3. "출처를 알 수 없는 앱" 설치를 막는다는 안내가 나오면 설정을 눌러 지금 쓰는 브라우저(Chrome 등)의 이 출처 허용을 켜고 뒤로 돌아와 설치를 누릅니다.
  4. Google Play 보호 경고가 나오면 자세히 → 무시하고 설치(또는 계속 설치)를 누릅니다.
  5. 설치가 끝나면 앱 목록에 주짓수 樂 아이콘이 생깁니다.
화면 문구는 제조사와 안드로이드 버전에 따라 조금씩 다릅니다. 스토어에 올라간 앱이 아니라서 위 경고가 나오는 것입니다. 앱은 사이트를 전체 화면으로 열어 주며, 유튜브 영상은 유튜브 앱이나 브라우저로 열립니다. 새 버전이 나오면 같은 버튼으로 다시 받아 설치하면 덮어씌워집니다.

"서명되지 않음"은 Apple에 등록된 회사 인증서로 서명하지 않았다는 뜻입니다. 이 파일은 사이트 운영자가 직접 만든 것입니다. 사이트로 돌아가기
